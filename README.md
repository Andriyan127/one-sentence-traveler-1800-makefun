## The entry

One sentence (120 characters) that explains the modern internet to a
time traveler who has just stepped out of the year 1800 — using only
words that plausibly existed in 1800, in a single vivid picture rather
than a list of features:

```
Imagine a library where every book answers back, and every letter reaches its reader before a struck bell stops ringing.
```
